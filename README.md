# iLoveWonik

> We are Wonik people.

## 소개

`iLoveWonik` 브랜치는 원익부트캠프 KDT 채용연계 프로젝트에서  
팀원들이 함께 공부하고 성장해서 원익에 들어가자는 의미로 만든 브랜치입니다.

## 브랜치 의미

이 브랜치에는 다음과 같은 의미가 담겨 있습니다.

- 원익부트캠프 KDT 과정을 함께 끝까지 완주하자
- 팀원들과 같이 공부하고 서로 도와주자
- 채용연계 프로젝트에서 좋은 결과를 만들자
- 모두 함께 성장해서 원익인이 되자

## 목표

- 원익부트캠프에서 배운 내용을 정리한다.
- 프로젝트 코드를 함께 관리한다.
- 팀원들과 학습 내용을 공유한다.
- 제조 AX/AI 프로젝트 역량을 키운다.
- 채용연계 과정에서 좋은 결과를 만든다.

## 협업 규칙

- 모르는 것은 혼자 끙끙대지 말고 질문한다.
- 아는 것은 팀원들에게 공유한다.
- 코드는 최대한 읽기 쉽게 작성한다.
- 커밋 메시지는 작업 내용을 알 수 있게 작성한다.
- 프로젝트 진행 상황을 꾸준히 기록한다.
